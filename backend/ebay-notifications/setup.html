Code 3 TCG eBay publisher setup

This local page helps the publisher copy the notification token and configure eBay. It does not edit inventory or prices.

Sign in to Code 3 TCG

Use your existing app account. Credentials go directly to your existing Supabase sign-in service. Nothing is saved in this browser.

1. Complete the eBay notification form

Failure email: support@code3tcg.com

Paste these into eBay's Marketplace Account Deletion form. Keep the token out of chat and screenshots. After eBay validates the endpoint and activates the keyset, return here.

2. Add the Production credentials

These go only to encrypted server storage. They are not placed in the phone app.

Then use Send Test Notification in eBay. Keep this page open for the completion check.
