# Code 3 TCG app and Discord bridge · October 29, 2026

Scout reads staff-approved community observations from the existing Code 3 TCG Discord ledger. A report submitted through the app's **Report in Discord** handoff follows the existing private form → staff review → approved Discord publication → shared app feed. This is a Discord submission handoff, not a new web submission form or an account-linking service. Private app drafts, workspace records, sign-in, and parent flows remain on their existing paths. No new login provider is presented as configured.

The feed exposes only public product/category, public store/link, status, observed time, area key and the existing Discord post URL. It excludes submitter/reviewer IDs, review notes, claims, queue state, privacy cases, photos and private app records. It is read-only and available without visitor credentials. Source data must be published with a verified delivery to a configured locality/Online/shared-local room, not withdrawn, observed within 24 hours, created on/after the October 29 cutover, and not a test/synthetic example. The latest published follow-up supersedes the earlier observation. Results are capped at 50 from a bounded candidate set. Old Discord history and the prior demonstration reports are not backfilled.

`supabase/community-feed.sql` adds one SECURITY INVOKER function with an empty search path. It revokes PUBLIC/anon/authenticated execution and grants only service_role. No existing table, data, policy or grant changes. `supabase/functions/code3-community-feed` exposes only the explicit safe projection over GET/HEAD/OPTIONS; POST/query parameters are rejected. Its gateway retains `verify_jwt=true`. The app supplies its existing public project anon key, omits cookies and never forwards a visitor's access token. This public key does not grant direct execution of the private RPC. Service credentials remain inside the same Code 3 TCG Supabase project. No bot token is needed by this new function. Storage failures return 503, never a successful empty inventory feed. No retailer page is fetched and no retailer scheduler or source setting is changed.
